# - 大模型推理与量化

#### 1. 简介

​	大型语言模型（LLM）由于其巨大的参数规模，在普通的消费级硬件上直接运行通常是不切实际的。这类模型可能包含数十亿的参数，主要体现为权重，这不仅带来了高昂的存储成本，同时在进行推理时也需要大量的计算资源。为了有效处理这些模型，通常需要依赖拥有较大显存的图形处理单元（GPU）来加速推理。

​	鉴于此，研究界正越来越多地探索缩小模型尺寸的方法，如优化训练技术或添加适配器组件等。量化（quantization）便是实现这一目标的关键技术之一，它有助于减少模型的大小和降低运算需求，从而使大型语言模型能够在资源更为有限的环境中部署和使用。
